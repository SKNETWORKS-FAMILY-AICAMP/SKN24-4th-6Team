개인정보처리방침

아이고 청년(이하 '본 서비스')는 정보주체의 자유와 권리 보호를 위해 「개인정보 보호법」 및 관계 법령이 정한 바를 준수하여, 적법하게 개인정보를 처리하고 안전하게 관리하고 있습니다. 이에 「개인정보 보호법」 제30조에 따라 정보주체에게 개인정보의 처리와 보호에 관한 절차 및 기준을 안내하고, 이와 관련한 고충을 신속하고 원활하게 처리할 수 있도록 하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다.

1. 개인정보의 처리 목적

본 서비스는 다음의 목적을 위하여 개인정보를 처리합니다. 처리하고 있는 개인정보는 다음의 목적 이외의 용도로는 이용되지 않으며, 이용 목적이 변경되는 경우에는 「개인정보 보호법」 제18조에 따라 별도의 동의를 받는 등 필요한 조치를 이행할 예정입니다.

  • 사용자가 업로드한 임대차계약서(PDF/이미지) 분석
  • 사용자가 입력한 질문·계약 조항 텍스트·논쟁 상황에 대한 AI 기반 답변 생성
  • 관련 법령 근거 및 판례 정보 제공
  • 계약 조항 검토 및 개선 제안

2. 처리하는 개인정보의 항목

본 서비스는 서비스 제공을 위해 필요한 최소한의 개인정보만을 처리합니다.

  • 서비스 이용 시 사용자 입력 정보: 업로드된 임대차계약서 텍스트 (PDF/이미지에서 추출), 채팅 질문 내용, 직접 작성한 계약 조항 텍스트

임대차계약서에는 당사자 성명, 주소, 주민등록번호 등 개인정보가 포함될 수 있습니다. 본 서비스는 계약 조항 검토에 필요한 텍스트만을 처리하며, 개인식별정보를 별도로 추출·저장하지 않습니다.

3. 개인정보의 처리 및 보유 기간

본 서비스는 개인정보를 별도로 저장하지 않으며, 다음과 같이 처리합니다.

  • 업로드된 계약서 텍스트: 새로운 파일 업로드 시 즉시 삭제 (서버에 영구 저장하지 않음)
  • 채팅 질문 및 응답 내용: 새 채팅 시작 시(세션 종료 시) 즉시 삭제 (브라우저 세션 메모리에만 존재)

본 서비스는 데이터베이스에 사용자 입력 정보를 저장하지 않으며, 브라우저 창을 닫거나 세션이 종료되면 모든 입력 데이터는 즉시 삭제됩니다.

4. 개인정보의 파기 절차 및 방법

  • 파기 절차: 세션 종료 시 서버 메모리에서 자동으로 삭제됩니다. 별도의 데이터베이스에 이전·보관하지 않습니다.
  • 파기 방법: 전자적 파일 형태로 처리된 정보는 메모리에서 즉시 해제되어 재생할 수 없도록 처리합니다.

5. 개인정보의 제3자 제공에 관한 사항

본 서비스는 원칙적으로 정보주체의 개인정보를 제3자에게 제공하지 않습니다.

단, AI 응답 생성을 위해 외부 LLM API를 활용할 수 있으며, 이 경우 사용자의 질문 내용이 해당 API 서비스로 전송됩니다. API 처리 완료 즉시 삭제됩니다.

6. 개인정보 처리업무의 위탁에 관한 사항

본 서비스는 현재 개인정보 처리업무를 외부에 위탁하고 있지 않습니다. 향후 위탁이 발생하는 경우 위탁받는 자와 위탁 업무의 내용을 본 개인정보 처리방침에 공개하겠습니다.

7. 개인정보의 안전성 확보조치에 관한 사항

  • 사용자 입력 데이터는 서버 메모리에서만 처리되며, 별도의 데이터베이스에 영구 저장하지 않습니다.
  • HTTPS를 통한 데이터 전송 암호화를 적용합니다 (배포 시).
  • 세션 종료 시 모든 사용자 데이터를 자동 삭제합니다.
  • 개인정보에 접근할 수 있는 담당자를 최소화하고 있습니다.

8. 정보주체와 법정대리인의 권리·의무 및 행사방법

정보주체는 본 서비스에 대해 언제든지 개인정보 열람·정정·삭제·처리정지 및 동의 철회 등을 요구할 수 있습니다.

  • 본 서비스는 사용자 데이터를 영구 저장하지 않으므로 세션 종료 시 모든 데이터가 자동 삭제됩니다.
  • 서비스 이용 중 개인정보 삭제를 원하시는 경우, 브라우저 창을 닫으시면 즉시 모든 데이터가 삭제됩니다.
  • 14세 미만 아동의 권리 행사는 법정대리인이 직접 해야 합니다.
